# Проект TeamFinder (Вариант 1)

Финальный проект курса Яндекс Практикум. Платформа для поиска единомышленников и совместной работы над pet-проектами.

## Возможности

- Регистрация и авторизация пользователей (email + пароль)
- Создание, редактирование и завершение проектов
- Участие в проектах других пользователей
- Добавление проектов в избранное
- Фильтрация пользователей по критериям
- Просмотр профилей пользователей
- Пагинация (12 элементов на страницу)

## Технологии

- Python 3.11
- Django 5.2
- PostgreSQL 16
- Gunicorn
- Nginx
- Docker / Docker Compose

## Структура приложений

- `team_finder` — основное приложение проекта (настройки, URL-маршруты)
- `users` — кастомная модель пользователя, регистрация, авторизация, профили
- `projects` — управление проектами, участники, избранное

- *В проекте нет реализации автотестов и CI/CD

## Права доступа

- Неавторизованные пользователи: только просмотр проектов и профилей
- Авторизованные пользователи: создание проектов, участие, избранное
- Администратор: полный контроль (через админ-панель)

## Запуск проекта через Docker

### 1. Клонируйте репозиторий

```
git clone <url-репозитория>
cd team-finder-ad
```

### 2. Создайте файл .env

```
cp .env_example .env
```

### 3. Запустите контейнеры

```
docker compose up -d --build
```

### 4. Выполните миграции

```
docker exec teamfinder_backend python manage.py migrate
```

### 5. Создайте суперпользователя

```
docker exec -it teamfinder_backend python manage.py createsuperuser
```

### 6. Соберите статику (если нужно)

```
docker exec teamfinder_backend python manage.py collectstatic --noinput
```

### 7. Откройте проект в браузере

```
http://localhost
```

### Дополнительные команды Docker

```
# Остановить все контейнеры
docker compose down

# Просмотр логов
docker compose logs -f

# Перезапустить контейнеры
docker compose restart

# Войти в контейнер бэкенда
docker exec -it teamfinder_backend bash
```

## Запуск без Docker

### 1. Создайте и активируйте виртуальное окружение

```
python3 -m venv venv
source venv/bin/activate
```

### 2. Установите зависимости

```
pip install -r requirements.txt
```

### 3. Настройте базу данных PostgreSQL

```bash
cp .env_example .env
```

После этого откройте `.env` и укажите свои значения.  

| Переменная            | Назначение                                                                                                                                                 |
|-----------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **DJANGO_SECRET_KEY** | Секретный ключ Django, используемый для подписи cookie и токенов. Можно сгенерировать при помощи `get_random_secret_key` из `django.core.management.utils` |
| **DJANGO_DEBUG**      | Режим отладки. Установите `True` во время разработки.                                                                                                      |
| **DJANGO_ALLOWED_HOSTS**       | Разрешенные для обращения к сайту адреса.                                                                                             |
| **POSTGRES_DB**       | Имя базы данных PostgreSQL, которую будет использовать Django.                                                                                             |
| **POSTGRES_USER**     | Имя пользователя PostgreSQL.                                                                                                                               |
| **POSTGRES_PASSWORD** | Пароль пользователя PostgreSQL.                                                                                                                            |
| **POSTGRES_HOST**     | Адрес сервера БД. В случае локальной разработки localhost.                                                                                                 |
| **POSTGRES_PORT**     | Порт подключения к БД (по умолчанию `5432`).

## 4. Запуск PostgreSQL

Для работы приложения **TeamFinder** используется база данных **PostgreSQL**.
По условию задания база данных должна запускаться в контейнере Docker.

В проекте уже есть пример файла `docker-compose.yml`. 
Используйте готовый или измените под свои нужды, а дальше запускайте:

```bash
docker compose up -d
```

`-d` значит `detach`, то есть контейнер продолжит работать в фоне. Чтобы его остановить, надо будет ввести

```bash
docker compose down
```

Если возникает ошибка "permission denied while trying to connect to the Docker daemon socket", то может потребоваться добавить `sudo` перед командой.

---

После этого база данных будет доступна по адресу `localhost:5432`.  
Нужно будет использовать эти же параметры в файле `.env`.

> Если на компьютере уже развёрнут сервер БД на порте 5432, и вы не хотите создавать БД для этого проекта на этом сервере, целесообразнее будет изменить порт на нестандартный.
> Нестандартный порт нужно будет поставить слева в паре портов в docker-compose (`"5433":"5432"`) и в .env.


### 5. Примените миграции

```
python manage.py migrate
```

### 6. Запустите сервер разработки

```
python manage.py runserver
```
Проект будет доступен по адресу: http://localhost:8000
